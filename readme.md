# Netflix Customer Churn Prediction System
Netflix user behaviour analysis
1. Put `netflix_user_behavior_churn_50000v2.csv` inside `data/`.
2. Double-click `setup.bat` — installs packages into your system Python.
3. Double-click `run.bat` — opens http://localhost:8501.
